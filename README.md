# Towering Clouds

Experimental Fabric mod for Minecraft 26.3 that replaces the flat cloud layer with
huge, towering cumulus cloud complexes.

Based on [Better Clouds](https://github.com/Qendolin/better-clouds) by Qendolin and
contributors, licensed under the Mozilla Public License 2.0 (see `LICENSE`).
This is an unofficial fork and is not affiliated with or endorsed by the Better Clouds authors.

## Build

Requires JDK 25.

    ./gradlew :fabric:build

The jar ends up in `fabric/build/libs/`.
